# fdf docs

fdf is a text data format made to be read and edited by hand. These pages cover the
format and the C++ API around it.

### The format

- [Syntax](Syntax.md) entries, comments, the overall shape of a document
- [Types](Types.md) scalars, packs, strings
- [Containers](Containers.md) maps, arrays, nesting

### The library

- [API](API.md) parsing, reading values, walking, editing, and combining trees
- [Styling](Styling.md) how documents get written back out
- [Diagnostics](Diagnostics.md) what happens on a parse error
- [Building](Building.md) requirements and build options

For real files to copy from, see [`../examples/`](../examples/README.md).
