# Examples

Real fdf you can copy from. Every file here is parsed and round-tripped by the test
suite, so they all stay valid.

- [`showcase.fdf`](showcase.fdf) a broad tour of the supported syntax, the one to read first
- [`access-policy.fdf`](access-policy.fdf) role-based permissions and session constraints
- [`asset.fdf`](asset.fdf) texture import metadata and platform variants
- [`config.fdf`](config.fdf) a realistic app config, the everyday case
- [`deployment.fdf`](deployment.fdf) a small web service deployment manifest
- [`experiment.fdf`](experiment.fdf) measurements from a laboratory instrument
- [`form.fdf`](form.fdf) a dynamic support request form
- [`invoice.fdf`](invoice.fdf) a business document with line items and totals
- [`localization.fdf`](localization.fdf) a UTF-8 translation catalog
- [`manufacturing.fdf`](manufacturing.fdf) an assembly record and production steps
- [`media-timeline.fdf`](media-timeline.fdf) ordered video and audio clips
- [`project.fdf`](project.fdf) a build/project spec, arrays of maps
- [`savegame.fdf`](savegame.fdf) persistent player and world state
- [`scene.fdf`](scene.fdf) game scene entities and transforms
- [`test-scenario.fdf`](test-scenario.fdf) an API request and expected response fixture

For the format and API reference, see [`../docs/`](../docs/README.md).
